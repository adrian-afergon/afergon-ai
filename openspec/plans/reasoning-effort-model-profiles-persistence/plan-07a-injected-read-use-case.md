## Interfaces and Technical Contracts

At `application/profile-document-observation.ts`, retain exact names: `ProfileDocumentObservation { sourceIdentity: string; exists: boolean; sourceBytes?: Uint8Array }`, `ObservedProfile { document: unknown; source: ProfileDocumentObservation; originalText?: string }`, and `LoadedProfile` with domain `RawProfileDocument`. It may extend the shared envelope, not redeclare an incompatible shape.
`ProfileObservationPort.observe(): ObservedProfile` lives in its application module. `ReadProfileDocumentUseCase(storage: ProfileObservationPort, validator: ProfileDocumentPolicy).execute(): LoadedProfile` observes once and delegates validation of the exact document with its source identity.
Present observations require actual Uint8Array bytes; absent observations forbid a byte payload. Copy the source envelope and bytes independently in both directions. A Buffer subtype's slice can alias memory: the application must use a genuine portable copy, without importing Buffer. Preserve raw-document identity and unknown data; optional originalText is retained, never generated by serialization.
Identity is a configured token, not an instruction to read a caller-selected path. The application neither parses raw bytes nor selects missing-file defaults. Those producer obligations belong to S07B.
